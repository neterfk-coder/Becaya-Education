Cómo se arma este calendario

Tres fuentes, una sola fecha de verdad.

  1. 01

    Se leen las fuentes oficiales

    La API de datos abiertos de Pronabec entrega las convocatorias vigentes del Estado peruano. Las becas internacionales se cargan y revisan a mano desde la web de cada institución.

  2. 02

    Cada beca guarda dos fechas

    Apertura y cierre. Sin esas dos fechas una convocatoria no entra al calendario, porque sin ellas no se puede saber si sigue viva.

  3. 03

    El estado se calcula solo

    Al cargar la página se comparan esas fechas con el día de hoy. De ahí salen los grupos: abierta ahora, abre esta semana, abre este mes, cerrada.
